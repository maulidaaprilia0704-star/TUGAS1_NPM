Daftar Kegiatan & Istilah

Jadwal Rutin Kegiatan

  1. Pagi Hari: Belajar Konsep Dasar
    • Membaca dokumentasi bahasa pemrograman baru
    • Menonton tutorial video pembelajaran & praktik singkat
  2. Sore Hari: Pembuatan Proyek Mini
    • Membuat kerangka struktur halaman web (HTML/CSS)
    • Melakukan uji coba kode di browser
  3. Malam Hari: Evaluasi dan Mengunggah Kode ke GitHub

Glosarium Istilah Pemrograman

HTML
Bahasa markup standar yang digunakan untuk membuat dan menyusun struktur halaman web.
Repository (Repo)
Folder atau tempat penyimpanan proyek yang dikelola menggunakan Git untuk melacak perubahan kode.
Debugging
Proses mencari dan memperbaiki kesalahan atau bug pada kode program.
